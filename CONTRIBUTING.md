# Contributing

Maintainer: Robin Gounder (Vaionex Corporation), robin@gounder.com. Report bugs and proposed changes through https://github.com/Kohze/numerical-range-certificates/issues or a pull request. Include a reproducible request, expected behavior, Python version and complete error text. Remove private model data before posting.

Certificate changes require review of the support inequalities, containment, mesh allowance and theorem provenance. Numerical comparisons alone do not establish validity. Include a meaningful regression for the corrected claim and preserve deterministic JSON evidence. Run `python -m unittest discover -s tests -v` and `python -B reproduce/check_saved_results.py` after installing the package.

Keep certificate construction/checking free of floating-point arithmetic. Label exploratory calculations accurately. A changed schema/evidence meaning needs a version decision; a changed theorem mode needs mathematical justification. Preserve historical timing observations and save new measurements separately.

The maintainer reviews contribution scope and release decisions. No response-time commitment or demonstrated community adoption is asserted.
